#Specialized Search Engines ( Wyszukiwarki specjalistyczne ) 

Shodan - Wyszukiwarka przeznaczona do szukania urządzeń podłączonych do Internetu ( Routery,kamery,serwery,porty).
Censys - Wszukiwarka przeznaczona do szukania w Internecie hostów,domen,certyfikatów i serwisów. 
VirusTotal - Serwis online który może przeskanować różnego rodzaju pliki, URL używając do tego różnych silników antyvirusowych.

# Vulnerability and Exploits ( Podatnośćii i eksploity)

CVE to standaryzowany identyfikator publicznie znanych podatności bezpieczeństwa.

Vulnerability  podatność / błąd w programie
Exploit	kod wykorzystujący tę podatność
Payload	co się stanie po wykorzystaniu exploita
Patch	poprawka naprawiająca podatność
Vulnerability → Exploit → Access

Exploit Database to publiczna baza kodów exploitów dla znanych podatności, używana w pentestach i badaniach bezpieczeństwa.

OSINT	zbieranie informacji z publicznych źródeł
Recon	rekonesans przed atakiem
Footprinting	zbieranie informacji o celu
Social Engineering	manipulowanie ludźmi
Phishing	fałszywe maile
Spear phishing	phishing celowany
OPSEC	ukrywanie swojej tożsamości
Digital footprint	ślady w internecie
