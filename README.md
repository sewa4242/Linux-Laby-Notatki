## Linux Laby i Notatki

Repozytorium dokumentujące moją naukę systemu Linux oraz podstaw cyberbezpieczeństwa (Blue Team).
Uczę się głównie poprzez praktykę – własne laboratoria na Ubuntu, pracę w terminalu oraz proste skrypty Bash.

## Najważniejsze projekty
1. system_check.sh – podstawowy health check systemu Linux
2. net_triage.sh – diagnostyka połączenia sieciowego
3. auth.log analyzer – analiza prób logowania SSH
4. Fail2Ban lab – konfiguracja ochrony przed brute force
5. Apache lab – instalacja i diagnostyka usługi WWW
6. LVM lab – tworzenie i rozszerzanie wolumenów logicznych

## Technologie
Linux, Bash, grep, awk, systemctl, journalctl, ss, Apache2, Fail2Ban, LVM.
